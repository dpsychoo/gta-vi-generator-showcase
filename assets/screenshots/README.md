# Screenshots — review before publishing

Add your **own approved screenshots** of the live project here once reviewed.

Suggested filenames:
- `landing-desktop.webp`
- `landing-mobile.webp`
- `upload-flow.webp`

Checklist:

- Use test images you have permission to publish (or no uploaded images at all).
- Never show a real customer's image, email, checkout data, order ID or token.
- Mask admin URLs, session identifiers, API responses and debug information.
- Avoid copying third-party game art, trailers, logos and character graphics into the public repository without permission.
- Prefer screenshots of original UI components, layouts and interactions.
- Compress WebP images, check mobile readability and add useful alt text to README image embeds.
- Do not take a real payment just to create screenshots.

When assets are available, update README.md's "Visual preview" section to include them. Until then, leave the page without broken image references.
